## Utkast: prompt till Kiro

> For work we're using kiro as our AI. In our repo we have a lot of agents and steering docs and other things that
> make kiro super useful and powerful for us to use. I'm planning on asking kiro to extract and summarize the parts of
> these docs that can be useful for you and make you easier to use. I want you to give me the prompt that I will give
> to kiro so that it can create for me a docs folder that will later give to you that makes you smarter and better.
> If my request is confusing then I want you to ask me to clarify
