# 📅 2024 MOC
En översikt över alla kurser och anteckningar från studieåret 2024.

## 📚 Kursindex
```dataview
LIST WITHOUT ID link(file.path, regexreplace(file.folder, "^.*/", ""))
FROM #index AND #year2024
SORT file.folder ASC
```

## 📝 Alla Anteckningar från 2024
```dataview
TABLE tags, file.mtime AS "Senast uppdaterad"
FROM #year2024
SORT file.name ASC
```
