# 📅 2025 MOC
En översikt över alla kurser och anteckningar från studieåret 2025.

## 📚 Kursindex
```dataview
LIST WITHOUT ID link(file.path, regexreplace(file.folder, "^.*/", ""))
FROM #index AND #year2025
SORT file.folder ASC
```

## 📝 Alla Anteckningar från 2025
```dataview
TABLE tags, file.mtime AS "Senast uppdaterad"
FROM #year2025
SORT file.name ASC
```
