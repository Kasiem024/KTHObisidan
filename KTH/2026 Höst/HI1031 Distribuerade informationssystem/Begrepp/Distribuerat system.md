# Distribuerat system

## Definition

Ett system där hård- eller mjukvarukomponenter på *skilda, nätverksanslutna* datorer samordnar sig ==enbart genom att skicka meddelanden== – utan delat minne eller gemensam klocka. Målet är att **dela resurser** (data, hårdvara, tjänster).
