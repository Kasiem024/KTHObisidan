# Middleware

## Definition

Ett *mjukvarulager* mellan operativsystem och applikation som ==maskerar heterogenitet== (olika nätverk, hårdvara, OS och språk) och erbjuder en enhetlig programmeringsmodell. Fungerar som en *universaltolk* mellan system som "talar olika språk". Exempel: CORBA, Java RMI, web services.
