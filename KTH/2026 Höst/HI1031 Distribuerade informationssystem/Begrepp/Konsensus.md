# Konsensus

## Definition

Problemet att få en grupp processer att ==enas om ett gemensamt värde==, trots att vissa kan fela. Det berömda *FLP-omöjlighetsresultatet* säger att konsensus inte kan garanteras i ett asynkront system om ens en process kan krascha – ändå når system i praktiken ofta överenskommelse.
